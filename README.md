# Ось — 3D-сайт (демо)

Лендинг с 3D-моделью часов: модель можно вращать мышкой или пальцем, есть смена отделки, анимации при скролле и плавный скролл.

Стек: Three.js (OrbitControls, RoomEnvironment), GSAP + ScrollTrigger, Lenis. Все библиотеки подключаются с CDN, сборка не нужна.

Запуск: открыть index.html через любой локальный сервер, например `npx serve .`, или включить GitHub Pages.

Бренд, цены и характеристики вымышлены.
